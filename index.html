🎓 Project Specifications & Working Mechanism

College Mini-Project Showcase
1. CRUD & LocalStorage State Machine

Provides complete Create, Read, Update, and Delete (CRUD) operations. Every administrative modification is serialized to JSON and persisted under the key office_notice_portal_items_v1, surviving full browser restarts without external databases.

2. Dynamic Real-Time Querying

Implements client-side JavaScript Array.prototype.filter() to evaluate simultaneous title substring searches, category criteria (General, Events, Exams, Holidays), and priority levels with instant DOM re-rendering.
